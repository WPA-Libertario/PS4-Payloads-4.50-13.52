### PS4-Payloads-4.50-13.52
### PS4 Payloads Update to 13.52 (October 22, 2026)

### Payload Descriptions
## Loading and Debugging Tools
- WebRTE (WebRTE-5-05_6-72_7-00-11-00.bin)
Function: Allows for the connection of trainers and external tools to modify games in real-time using cheats.
Compatible versions: 5.05, 6.72, and 7.00–11.00.

- Bin Loader (elfldr-4-50-5-07_7-00-9-60.bin)
Function: Loads custom binary files onto the console over the network.
Compatible versions: 4.50–5.70 and 7.00–9.60.

- Elf Loader (elfldr.elf)
Function: Loads and executes ELF-format executable files on the console.
Compatible versions: 4.71–13.52.

- PS4 Debug (ps4debug-ng_v1.3.2.bin)
Function: An advanced debugging tool for developers that enables memory access, process dumping, and application debugging.
Compatible versions: 4.73–13.52.

## Data Management, Backups, and Storage
- Database Rebuilder (db-rebuilder-v0.2.bin)
Function: Rebuilds the console's database to resolve issues such as games failing to appear or corrupted data.
Compatible versions: 4.73–13.52.

- APP (pkg) Dumper (ps4-app-dumper.bin)
Function: Allows for dumping games—whether installed from a disc or a digital source—back into a .pkg file, which can then be used for backups or modifications.
Compatible versions: 4.73–13.52. 

- App2USB (ps4-app2usb.bin)
Function: Allows for moving installed applications and games from internal storage to an external hard drive or USB flash drive.
Compatible versions: 4.73–13.52.

- Backup DB + Licence + User Data (ps4-backup.bin)
Function: Performs a full backup of the database, licenses, and user data.
Compatible versions: 4.73–13.52.

- Restore DB + Licence + User Data (ps4-restore.bin)
Function: Restores a previously created backup of the database, licenses, and user data.
Compatible versions: 4.73–13.52.

- Kernel Dumper (ps4-kernel-dumper.bin)
Function: Extracts a copy of the console's current kernel for technical analysis and development purposes.
Compatible versions: 4.73–13.52.

- Module Dumper (ps4-module-dumper-4-73-13-00.bin)
Function: Dumps the operating system modules currently loaded into memory.
Compatible versions: 4.73–13.00.

- PUP Decrypt (ps4-pup-decrypt.bin)
Function: Decrypts the console's official update files (PUP files).
Compatible versions: 4.73–13.52.

## System, Network, and Update Control

- NP Fake Signin (np-fake-signin-ps4.elf)
Function: Simulates a fake sign-in to the PlayStation Network (PSN) for local testing.
Compatible versions: 4.71–13.52.

- PS4 Disable ASLR (ps4-disable-aslr.bin)
Function: Temporarily disables Address Space Layout Randomization (ASLR); useful for code debugging.
Compatible versions: 4.73–13.52.

- PS4 Disable Update (Versions 4.50–5.07 and 4.73–13.52)
Function: Blocks the automatic download and installation of system firmware updates.
Compatible versions: Depending on the file, covers the 4.50–5.07 or 4.73–13.52 ranges.

- PS4 Enable Update (ps4-enable-updates-4-73-13-52.bin)
Function: Reverts the update block, allowing the console to search for software patches again.
Compatible versions: 4.73–13.52.

- Enable Browser (ps4-enable-browser-4-50-5-07.bin)
Function: Enables the web browser on consoles where it is restricted.
Compatible versions: 4.50–5.07.

- Exit IDU (ps4-exit-idu.bin)
Function: Exits the retail demo mode (IDU - Interactive Display Unit) and returns the console to normal operation.
Compatible versions: 4.73–13.52.

- FTP (Versions 4.50–5.07 and 4.73–13.52)
Function: Launches an FTP server on the console, allowing for direct file transfers from a PC via the local network.
Compatible versions: 4.50–5.07 or 4.73–13.52 ranges, depending on the selected file.

- History Blocker (ps4-history-blocker.bin)
Function: Blocks web browsing history and the recording of visited pages within the console's web browser for enhanced privacy.
Compatible versions: 4.73–13.52.

- Permanent/Output UART (ps4-permanent-uart.bin)
Function: Enables or makes permanent the debug output via the physical UART port on the console's motherboard.
Compatible versions: 4.73–13.52.

- RIF Rename/Manipulate (ps4-rif-renamer.bin)
Function: Allows for the renaming or manipulation of license files (.rif) for games and downloadable content.
Compatible versions: 4.73–13.52.

- Southbridge Detector (ps4-southbridge-detector.bin)
Function: Identifies the model of the Southbridge chip integrated into the console's motherboard.
Compatible versions: 4.73–13.52.

- Web Server (ps4-websrv.bin)
Function: Launches an internal local web server on the PS4.
Compatible versions: 4.73–13.52.
